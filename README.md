# 📚 Core — Notes & Previous Year Questions

Welcome to **Core**! This repository is a collection of academic resources to help students prepare for exams and strengthen their understanding of different subjects.

## 📖 What's Inside?

This repository will contain:

- 📝 **Notes:** Subject-wise notes for quick learning and revision.
- 📄 **PYQs (Previous Year Questions):** Previous year question papers and questions to help you understand exam patterns.
- 📚 **Study Materials:** Additional resources that may be useful for your academic preparation.

The resources will be organized subject-wise to make them easy to find and use.

## ⬇️ Download or Clone the Repository

You can access the resources in either of the following ways.

### Option 1: Download as ZIP

1. Open the [Core repository](https://github.com/Krishna240517/Core).
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file to access the materials.

### Option 2: Clone the Repository

If you have Git installed, open your terminal and run:

```bash
git clone https://github.com/Krishna240517/Core.git
```

Then enter the repository folder:

```bash
cd Core
```

## 🤝 Want to Contribute?

Contributions are welcome! You can help by adding notes, previous year questions, correcting mistakes, or improving the organization of the resources.

Follow these simple steps:

### Step 1: Fork the Repository

Open the [Core repository](https://github.com/Krishna240517/Core) and click **Fork** in the top-right corner. This creates a copy of the repository in your GitHub account.

### Step 2: Clone Your Fork

Replace `YOUR-USERNAME` with your GitHub username:

```bash
git clone https://github.com/YOUR-USERNAME/Core.git
cd Core
```

### Step 3: Create a New Branch

Create a separate branch for your contribution:

```bash
git checkout -b add-subject-material
```

### Step 4: Add Your Files

- Add your notes or PYQs to the appropriate subject folder.
- If a suitable folder doesn't exist, create one.
- Use clear and meaningful file names.
- Prefer PDF files for notes and question papers whenever possible.

### Step 5: Commit Your Changes

Save your changes to Git:

```bash
git add .
git commit -m "Add subject notes and PYQs"
```

### Step 6: Push Your Changes

```bash
git push origin add-subject-material
```

### Step 7: Create a Pull Request

1. Open your fork on GitHub.
2. Click **Compare & pull request**.
3. Add a short description of what you contributed.
4. Click **Create pull request**.

That's it! Your contribution will be reviewed before being merged into the main repository. 🎉

## ✅ Contribution Guidelines

- Keep files organized by subject and topic.
- Upload accurate, readable, and relevant study materials.
- Avoid duplicate files and unnecessary clutter.
- Use meaningful file names.
- Make sure you have permission to share any material you upload.
- Be respectful and helpful to other contributors.
